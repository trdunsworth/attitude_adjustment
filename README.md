## Getting Started

### Prerequisites

- [Obsidian](https://obsidian.md/) installed on your device

### Quick Start Guide

1. **Set Up Your Workspace**

   ```bash
   # Clone this repository
   git clone <this-repo-url>
   cd attitude-adjustment
   
   # Copy template files to Obsidian templates folder
   # On macOS: cp *.md ~/Library/Application\ Support/Obsidian/
   # On Windows: Copy to %APPDATA%/Obsidian
   ```

2. **Configure Obsidian**
   - Enable "Templates" in Settings > Templates
   - Set your default folder
   - Install the "Daily Notes" plugin for automatic daily log creation

3. **Create Your First Reflection**
   - Use the **Daily Reflection Template** for quick daily check-ins
   - Start with just 5 minutes each day
   - Focus on one Attitude Adjustment goal for the day

4. **Establish Your Routine**

   ```
   Morning: Daily Reflection + Tarot Reading
   Evening: Daily Log + Goal Review
   Weekly: Weekly Reflection
   Monthly: Personal Measurements review
   Annually: Annual Progress Review
   ```

### Recommended Usage Workflow

#### Daily

1. Start morning with **Daily Reflection Template** (5-10 minutes)
2. Complete **Daily Tarot Reading Template** for guidance and focus
3. Log activities in **Daily Log Template** at day's end
4. Update **Goals Checklist** with completed tasks

#### Weekly

1. Use **Weekly Reflection Template** for comprehensive review
2. Review progress in **Research Tracker**
3. Update **Wisdom Sources Tracker** based on applications

#### Monthly

1. Assess metrics in **Personal Measurements Template**
2. Track progress trends and adjust goals
3. Prepare notes for upcoming annual review

#### Quarterly

1. Complete **Annual Progress Review Template**
2. Identify key learnings and insights
3. Set next year's priorities

## Configuration for Obsidian

### Template Folder Setup

1. In Obsidian, go to Settings > Templates
2. Click "Open Templates Folder"
3. Copy these files to your templates folder:
   - `daily_reflection_template.md`
   - `weekly_reflection_template.md`
   - `daily_tarot_reading_template.md`
   - `habit_tracker_template.md`
   - `daily_log_template.md`
   - `personal_measurements_template.md`
   - `annual_progress_review_template.md`

### Command Palette Usage

- Use `/template` to quickly insert any template
- Use `/daily note` to create new daily logs
- Use `/tag` to browse available tags

## Tips for Effective Use

### Starting Out

1. **Begin Simply**: Start with daily reflection for just 5 minutes
2. **Focus on One Goal**: Pick one Attitude Adjustment goal to concentrate on initially
3. **Be Consistent, Not Perfect**: Missed a day? Just resume the next day
4. **Use the Template**: Let the structure guide your thinking

### Building Momentum

1. **Review Weekly**: Use the weekly reflection to identify patterns
2. **Adjust as Needed**: Update goals and metrics based on real progress
3. **Integrate Wisdom Sources**: Connect daily experiences to wisdom teachings
4. **Celebrate Small Wins**: Track and acknowledge progress, no matter how small

### Long-term Success

1. **Annual Review**: Use the comprehensive review to assess real transformation
2. **Share Insights**: Apply learnings to help others (mission creep)
3. **Stay Flexible**: Let the system evolve with your needs
4. **Maintain Balance**: Focus on living well, not just tracking perfectly

## Troubleshooting

### Common Issues

- **Hard to Get Started**: Try using only the Daily Reflection Template for the first week
- **Forgetting to Log**: Set phone reminders or use Obsidian's daily notes plugin
- **Too Much Structure**: Focus on just 2 templates initially (Daily Reflection + Daily Log)
- **Disappointing Results**: Remember this is a living project - adjust as needed
